# 🏛️ Portal de Extensão FECISC / UECE

> Portal institucional desenvolvido para a Faculdade de Educação e Ciências Integradas do Sertão de Canindé (FECISC/UECE), focado em desempenho, acessibilidade e gestão prática de conteúdo.

🔗 **Acesse a aplicação:** [extensao-adm-caninde.vercel.app](https://extensao-adm-caninde.vercel.app/)

---

## 💻 Sobre o Projeto

O projeto foi concebido para atender às demandas de comunicação e divulgação dos cursos e projetos de extensão da instituição. A arquitetura foi planejada para entregar alta velocidade de carregamento por meio de páginas estáticas, otimização de mídias e integração com CMS headless, permitindo atualizações de conteúdo em tempo real sem a necessidade de alteração no código.

O trabalho foi apresentado e aprovado em Reunião de Colegiado do curso de Administração da faculdade.

---

## 🛠️ Tecnologias Utilizadas

- **Framework / Core:** Next.js, React, HTML5, CSS3, JavaScript
- **Gerenciador de Conteúdo (CMS):** Contentful (Headless CMS)
- **Hospedagem & Deploy:** Vercel

---

## ✨ Principais Destaques

- **Desempenho & Otimização:** Renderização estática para máxima velocidade de carregamento e otimização de ativos de mídia.
- **Gestão Headless:** Integração via API com Contentful CMS para atualização dinâmica de conteúdos.
- **Acessibilidade & Responsividade:** Interface adaptada para diferentes dispositivos e tamanhos de tela.

## 🚀 Como Rodar o Projeto Localmente

```bash
# Clone este repositório
$ git clone [https://github.com/Leone0038/extensao-adm-caninde.git](https://github.com/Leone0038/extensao-adm-caninde.git)

# Acesse a pasta do projeto
$ cd extensao-adm-caninde

$ npm run dev
